## setext 見出しの描画 (改訂38)

> `text` の直下 (空行なし) の `---` / `===` は罫線ではなく**上の行を見出しにする下線** (CommonMark)。従来は無処理で `---` が露出していた。

- [x] **`foo` ⏎ `---` で foo が H2 見出しになり、`---` が消える**
- [x] `foo` ⏎ `===` で foo が H1 見出しになる
- [x] 下線が消えた分の**空行の隙間が空かない** (行が潰れている)
- [x] **下線行にカーソルを移すと `---` が再表示され、編集できる**
- [x] カーソルを外すとまた見出し表示に戻る
- [x] **`foo` ⏎ 空行 ⏎ `---` は従来どおり罫線**として表示される
- [x] ツールバーの水平線ボタンは (空行を入れるので) 罫線になる
- [x] 既存ファイルで意図せず見出しになってしまう箇所がないか、手持ちの md をいくつか開いて確認
