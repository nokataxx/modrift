## iCloud 異常系 — **審査で踏まれやすい**

> 審査員は iCloud にサインインしていない端末で試すことがある。開発中、iCloud 状態が壊れたシミュレータで**マイファイルが読み込み中のまま固まりタップも効かなくなる**事象を観測した (原因はシミュレータ環境だが、実機でも iCloud 未サインイン時の挙動は要確認)。

- [x] **iCloud Drive をオフ / サインアウトした状態でアプリを起動 → 固まらない** → **懸念していたフリーズは発生せず、本項目の目的は達成**。実測では iCloud を OFF にしても一覧・閲覧ができた (ubiquity コンテナのローカル実体が端末に残り `getContainerDocumentsURL` がそのパスを返すため)。**「空表示かエラーで返る」という期待値の書き方が不正確だった** — 使えてしまうこと自体は不具合ではない
- [x] 同状態で「＋」新規作成 → **作成が成功するためダイアログは出ない。無言の失敗ではないので問題なし**。ダイアログが要るのは `getContainerDocumentsURL` が null を返す場合のみ (`IcloudUnavailableError` 経路)
- [x] 同状態で設定からホームを「この iPhone」に切り替えれば正常に使える
- [x] 機内モード / オフラインでホームの一覧・閲覧・編集ができる (同期は後追い)
