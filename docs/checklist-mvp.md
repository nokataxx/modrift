## 実機検証チェックリスト (MVP リリース判定)

[Requirements.md](Requirements.md) 11章の受け入れ基準のうち、**コードでは確認できず実機操作が必要な項目**。実機で一つずつ潰す用。

> **凡例**: `[x]` = 検証完了。`→` で始まる注記は実機で観測した所見の記録。問題が見つかったものは消さず、**「解決済み。当初の所見: …」**の形で残す（記録を保持しつつ、未解決と誤読されないようにするため）。

### 起動経路 (2つの経路)

- [x] 経路A: アプリ内「ファイルを開く」→ Document Picker → iCloud Drive の `.md` を開ける
- [x] 経路B: Files App で `.md` を長押し → 「Modrift で開く」で起動して該当ファイルが表示される
- [x] 経路B (Open In): Drive 等のファイルを Open In → iCloud コピーのダイアログ → コピーして preview 表示

### プレビュー表示

- [x] 見出し / リスト / リンク / コード / 引用 / HTTPS画像 が正しく表示される
      → 見出し / リスト / リンク / コード / 引用 はOK
      → 画像は記法で3種類に分かれる。混同しないよう区別する:
        - `![[画像.png]]` (Obsidian 埋め込み=ローカル): CommonMark 非対応のため**生テキスト `[[画像.png]]` がそのまま表示**される。これは仕様通り (10.3 / FR-02)。実機で確認済み。
        - `![alt](画像.png)` (標準Md のローカル相対パス): `[画像: 画像.png]` プレースホルダ表示 (FR-02、仕様通り)。
        - `![alt](https://.../画像.png)` (HTTPS画像): 仕様では**実際に表示**される。受け入れ基準 (11章) の対象はこれ。**実機 Modrift で表示を確認済み**（[samples/showcase.md](../samples/showcase.md) の HTTPS 画像が表示された）。当初「真っ黒」と観測したのは確認に使った URL が無効 (HTTP 400) だったためで、Modrift 側の不具合ではなかった。
      → 補足: Obsidian の標準的なローカル画像は `![[image.png]]` 記法のため、Vault ユーザーのローカル画像は `[画像:…]` プレースホルダではなく生の `[[…]]` テキストで出る。FR-17 (Obsidian風リンク, v2) で扱う範囲。
- [x] 引用が読める背景＋文字色になっている (← 今回修正、要再確認)
- [x] インラインコードが枠線で囲まれず淡い背景だけ (← 今回修正、要再確認)
- [x] リンクが青＋下線で表示され、タップでブラウザが開く (← 今回修正、要再確認)
- [x] ローカル画像はプレースホルダ表示
- [x] ライト/ダーク両方で破綻がない
