# v2 実機検証チェックリスト

v2 で実装した機能のうち、**シミュレータ／ヘッドレス Chrome では確認しきれず実機操作が必要な項目**。実機ビルド時に一つずつ潰す用。

> 凡例: `[ ]` = 未検証 / `[x]` = 実機で確認済み / `[-]` = v2 では見送り（任意項目）。`→` は補足・所見。

**運用**: 各機能を実装・コミットするタイミングで、その実機検証項目をこのファイルに逐次追記する（鮮度優先）。**v2 の開発が一通り終わったら、実機検証に入る前に一度「整理パス」を実施する**:
- 画面/フロー順に並べ替え
- 重複・陳腐化した項目を削除
- 「シミュレータ済み / 実機必須」の区分を再確認
- 横断項目の補完（ダーク・ライト両方 / 日英両方 / iPhone・iPad 両方）

> **v2 の現状 (2026-07-03)**: 実装済みは **FR-20（閲覧＋編集を CodeMirror 一本化）** とその依存整理（enriched-markdown 撤去・設定プレビューの CM 化）。附随機能（全文検索 FR-15 / 編集履歴 FR-19 / 見出しスタイル FR-25 / iPad 最適化 FR-16）は**未実装**なので、実装したら本ファイルに検証項目を追記していく。

> **なぜ v2 は実機確認の比重が高いか（重要）**: FR-20 でレンダリングが **Native (TextKit) → WKWebView 上の CodeMirror** に変わった。WKWebView は `@font-face` の `size-adjust` を無視する等、**ヘッドレス Chrome と実機 WebKit で描画が乖離する**（[[project_ios_webkit_size_adjust_ignored]]）。ヘッドレス確認は開発の当たり付け止まりで、**見た目・フォント・IME は必ず実機で最終確認**する。

## ライブプレビュー編集の基本 (FR-20)

> 閲覧・編集を単一の CodeMirror エディタで賄う。ヘッダーの編集/プレビュー トグルは**リロードせず** editable を切り替える（履歴・スクロール位置維持）。

- [ ] **閲覧モードは記法マーカーを見せず整形表示、編集モードはカーソル行だけ生の記法を露出する**（Obsidian 風ライブプレビュー）
- [ ] **編集 ⇄ プレビュー トグルで内容・スクロール位置・undo 履歴が保たれる**（リロードによるチラつき・先頭戻りが無い）
- [ ] **in-place 編集可（iCloud/ローカル）はヘッダーに編集ボタン、非 in-place（Google Drive 等）は編集ボタンでなく iCloud コピー作成ボタンが出る**
- [ ] **WebView 初期表示で白フラッシュが出ない**（`theme.background` で塗って初期化前も背景一致）
- [ ] キーボード表示時にエディタが隠れない（`KeyboardAvoidingView` + `headerHeight` オフセットが実機で正しい）

## Markdown レンダリング（実機 WebKit 必須）

> 各要素が実機のライト・ダーク両方で、見た目が旧 Native レンダラの体裁に沿って崩れず出るか。

- [ ] **見出し H1〜H6** — サイズ・色階層（H1 ネイビー / H2 薄ネイビー / H3・H4 ニュートラル）、太字化しない方針
- [ ] **太字・斜体・打ち消し線（GFM）・inline code**
- [ ] **箇条書き / 順序付きリスト / ネストリスト** — 行間 base×1.65、インデントが実機で自然か
- [ ] **引用 / ネスト引用** — 左アクセントバー、角丸
- [ ] **水平線（`---`）がライト・ダーク両方で見える**（極薄で埋もれない）
- [ ] **コードブロックがシンタックスハイライト付きで出る** — 対応言語は色分け、未対応言語は等幅＋単色フォールバック、角丸カード
- [ ] **テーブル（GFM）** — 罫線グリッド、ヘッダ網掛け無し、横スクロール可
- [ ] **画像** — https は inline 表示、ローカル/相対パスは `[画像: ファイル名]` プレースホルダ（i18n）
- [ ] **CJK/Latin 混在の字面が揃う** — 和文ヒラギノ＋英 SF、`palt`、CJK 隣接スペース圧縮。size-adjust を使わず inline font-size span で調和（実機と Chrome で差が出る箇所）
- [ ] **文字サイズ設定（小/中/大）で本文・見出し・コードが一体でスケール**する

## タスクチェックボックスのタップ

> savable（iCloud 等 in-place 編集可）なファイルでのみタップ切替可（`taskInteractive`）。

- [ ] **`- [ ]` / `- [x]` がボックスとして描画される**（枠 textSecondary、ON は tint 塗り＋チェック）
- [ ] **タップで ON/OFF が切り替わり、記法（`[ ]`↔`[x]`）が書き換わって自動保存される**
- [ ] **チェック ON/OFF でボックスの縦位置がズレない**（ベースライン固定）
- [ ] **非 savable（閲覧のみ）のファイルではタップしても切り替わらない**

## リンクのタップ

- [ ] **閲覧モードでリンクをタップすると外部（Safari 等）で開く**
- [ ] 編集モード中はリンクタップで開かず、テキストとして編集できる
- [ ] 不正・未対応スキームのリンクをタップしてもクラッシュしない（握りつぶし）

## Undo / Redo（CodeMirror history）

> undo/redo は自前スタックでなく CM 内蔵 history に委譲。編集モード時のみヘッダーにアイコン。

- [ ] **編集モードのヘッダーに undo/redo が出る**（プレビュー時は出ない。スタックが空なら淡色＝無効）
- [ ] **連続入力 → undo 1回でその塊がまとめて戻る**（1文字ずつでない）
- [ ] undo/redo を往復しても内容が壊れない（途中で別編集を入れると redo がクリア）
- [ ] **ファイル切替・「最新版を取得」で履歴がリセットされる**（別ファイルの undo が混ざらない＝ key remount）
- [ ] undo した状態が 3秒後に自動保存される / 再オープンで保持される

## 日本語 IME（WebView CodeMirror）

> 編集器が Native TextInput → WKWebView 上の CM に変わり、composition の扱いが変わった。**実機 IME 必須**。

- [ ] **日本語変換中（未確定）の表示が崩れない** — 変換候補・確定操作が正常
- [ ] **変換確定したテキストだけが保存に渡る**（未確定文字が二重に入らない）
- [ ] IME 入力中に undo/redo してもクラッシュ/文字化けしない
- [ ] 自動保存（3秒 debounce）と IME 確定が重なっても壊れない

## 自動保存・競合・iCloud コピー（CM 経由での回帰確認）

> ロジックは viewer.tsx に維持されているが、編集が CM 経由になったので回帰確認する。

- [ ] **編集の 3秒後に自動保存される**（再オープンで反映）／バックグラウンド遷移・画面離脱でも保存される
- [ ] **前景復帰時に外部変更を検知して競合ダイアログが出る**（FR-13。手順は v1.1 チェックリスト参照）
- [ ] 未保存編集が無い状態の前景復帰では静かに最新へ追従（誤ダイアログ無し）
- [ ] **非 in-place ソースで編集ボタン → iCloud コピー作成ダイアログ → コピーが編集モードで開く**（原本に書き戻さない）
- [ ] Open-In / 共有の使い捨てコピーは、編集せず離脱で消える／編集で iCloud 昇格（既存フロー維持）
