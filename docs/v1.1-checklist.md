# v1.1 実機検証チェックリスト

v1.1 で実装した機能のうち、**シミュレータでは確認しきれず実機操作が必要な項目**。実機ビルド時に一つずつ潰す用。

> 凡例: `[ ]` = 未検証 / `[x]` = 実機で確認済み。`→` は補足・所見。

## ネットワーク監視 (FR-12)

- [ ] **オフライン → オンライン復帰バナーが表示される**
      → オフライン表示（オレンジ「オフライン」）はシミュレータで確認済み。
      → **復帰（緑「オンラインに復帰しました」）はシミュレータでは検証不可** — iOS シミュレータは Wi-Fi トグル後セッション中にネットワーク復帰を認識しない既知の制約のため。実機の機内モード ON→OFF で確認する。
- [ ] オフラインバナーがホーム・ビューア両方で出る

## 設定画面 (FR-09 / FR-10)

- [ ] **外観カードのサイズ感が実機で細かすぎないか** — 小さければ `src/app/settings.tsx` の `swatchOuter` の `width/height` を拡大
- [ ] 文字サイズ 小 / 中 / 大 が実機で読みやすいか（小で詰まりすぎ・大で大きすぎがないか）
- [ ] 外観 システム / ライト / ダーク の切り替えが実機で破綻しないか（見出しネイビー含む）
- [ ] ライブプレビューが設定変更に追従して即更新されるか

## 見出しカラーリング

- [ ] H1 ネイビー / H2 薄ネイビー / H3・H4 ニュートラルが実機のライト・ダーク両方で読みやすいか

## 競合警告UI (FR-13)

> シミュレータでは「別デバイスからの同期」を再現しづらいため、実機 + iCloud Drive での確認が必要。再現手順例: ① 実機A の Modrift でファイルを開いて編集 → ② 別デバイス (Mac の Finder / iCloud.com / 実機B) で同じファイルを更新 → ③ 実機A で編集して自動保存を待つ。

- [ ] **外部変更後の保存で警告ダイアログが出る** — 「ファイルが変更されています」が表示される
- [ ] **「編集中の内容を保持」で上書き保存できる** — 自分の編集が残り、再度開いても保持されている
- [ ] **「最新版を取得」で外部版に差し替わる** — エディタ・プレビューとも最新の内容になり、自分の編集は破棄される（編集モード中でもエディタが追従する）
- [ ] 競合が無い通常編集では従来どおりサイレントに自動保存される（誤検知でダイアログが出ない）

## Markdown 要素のテーマ連動色

- [ ] **チェックリスト（`- [x]`）のチェックON項目がダークモードで読める** — ライブラリ既定の `checkedTextColor` が黒固定で消えていた。`theme.text`（通常本文色・取り消し線なし）に修正。ライト・ダーク両方で確認
- [ ] **水平線（`---`）がライトモードで見える** — ライブラリ既定が極薄グレー（`#E5E7EB`）で白背景に埋もれていた。`theme.textSecondary` に修正。ライト・ダーク両方で確認
