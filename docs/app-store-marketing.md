- ポジショニングは **「どこのファイルでも開ける軽量 Markdown ビューア＆クイックエディタ」**（2026-06-29 方針転換・[Requirements 改訂11](Requirements.md)）。**フォルダ Vault は廃止**（iOS がサードパーティのフォルダ参照を塞ぐため）。
  主語は Markdown、**Obsidian は「橋＝コンパニオン」としての互換の証拠**に置く（商標回避のため app 名には入れない）。差別化＝「全プロバイダの単一 Md を整形して軽快に開く」。

## タイミングの制約（重要）

ASO の **title / subtitle / keyword はバージョン紐付けメタデータ**。承認済みでも変更には
**新しいバージョン＝新ビルド＋再審査**が必要（Promotional Text のみ例外で随時変更可）。

→ いま v2 を開発中なので、**ASO 変更は v2 提出に同梱**するのが追加工数ゼロで最適。
v2 まで待てない明確な理由があるときだけ、軽微な `v1.1.1`（メタデータ＋bump）を切る。

> **✅ 実行済み（2026-08-13）**: この同梱方針どおり、2.0.0 の提出でサブタイトル・キーワード・説明文・
> プロモーションテキスト・スクリーンショットをまとめて差し替えた。次に ASO を触れるのは次バージョンの提出時。
