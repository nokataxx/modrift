## 前提（フェーズと目的）

- v1.1 は **Apple 審査通過済み（2026-06-28）**。開発は **v2 ブランチ**で進行中（main = リリース安定線）。
- v1.1 / v2 の当面の目的は **集客ではなく「学習と土台作り」**。
  無料コア（Md 閲覧・編集）を配り切り、レビュー資産とインストールベースを積み、v3（PDF/xlsx 単一ファイル閲覧の有償 Pro）の
  有償転換に備える。→ v1.1 では広告プッシュ・レビュー催促はしない。
- ポジショニングは **「どこのファイルでも開ける軽量 Markdown ビューア＆クイックエディタ」**（2026-06-29 方針転換・[Requirements 改訂11](Requirements.md)）。**フォルダ Vault は廃止**（iOS がサードパーティのフォルダ参照を塞ぐため）。
  主語は Markdown、**Obsidian は「橋＝コンパニオン」としての互換の証拠**に置く（商標回避のため app 名には入れない）。差別化＝「全プロバイダの単一 Md を整形して軽快に開く」。

## タイミングの制約（重要）

ASO の **title / subtitle / keyword はバージョン紐付けメタデータ**。承認済みでも変更には
**新しいバージョン＝新ビルド＋再審査**が必要（Promotional Text のみ例外で随時変更可）。

→ いま v2 を開発中なので、**ASO 変更は v2 提出に同梱**するのが追加工数ゼロで最適。
v2 まで待てない明確な理由があるときだけ、軽微な `v1.1.1`（メタデータ＋bump）を切る。

| Subtitle / Description | 変更不要（元から Vault 非依存・単一ファイル軸） | — |
| スクリーンショット | 変更不要（公開中の3枚は v1.1 由来で Vault UI を含まない。Vault は未出荷） | — |

→ 当面のアクションは **(1) Promo をストアに即反映（誤訴求の解消）**、**(2) 残りのメタデータ変更を v2 提出に同梱** の2つ。

**タイトルの category 語: `エディタ` か `ビューア` か**

- `ビューア`案: v1.1 はライブプレビュー未実装のため、"エディタ" だと重い編集を期待され

## 注意点メモ

- **編集（クラウド書き戻し）が成立するのは iCloud Drive のみ**（コード確定: `isInPlaceEditable()` が
  iCloud Drive とアプリの iCloud コンテナだけを編集可とし、Dropbox/Google Drive 等は一律
  「iCloud にコピーして編集」へ流す）。訴求文では **編集＝iCloud Drive、Dropbox/Google Drive＝閲覧**
  と書く。「iCloud/Dropbox は編集おすすめ」とは書かない。
- ✅ **既存ドキュメントの訂正は完了（2026-06-28）**: [app-store-listing.md](app-store-listing.md)（ja/en）・
  [../CLAUDE.md](../CLAUDE.md)・[Requirements.md](Requirements.md) を「編集＝iCloud Drive のみ／Dropbox・
  Google Drive は閲覧」に統一済み。
  - ⚠️ **ただし repo の修正 ≠ ストア公開文の修正**。listing.md はライブのストア掲載文の下書きで、
    **App Store 上の説明文を実際に直すには新ビルドの提出が必要**（説明文もバージョン紐付けメタデータ）。
    → **訂正済みの説明文は v2（または小バージョン）提出に同梱して初めて公開に反映される**。それまでは
    ストア上に「Dropbox は編集同期」という誤った旧文言が残る点に注意。下記 B にタスク化。
- v1.1 が **Pending Developer Release（手動リリース待ち）**なら、実際に「リリース」を押すまで非公開。
- 文字数上限（実機で確定前に再確認）: サブタイトル 30字 / キーワード 100字 / プロモ 170字。
