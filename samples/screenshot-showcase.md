## Why Markdown

> Plain text you own, formatted the moment you open it — no lock-in, no heavy vault.

Inline code like `npm run build` stays readable, and fenced blocks keep their shape:

```ts
export function greet(name: string) {
  return `Hello, ${name}`;
}
```
