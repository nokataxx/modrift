# FR-18 画像表示テスト

このノートは **Vault フォルダ内のローカル画像が表示されるか**を確認するためのファイルです。
設定で **このファイルが入っているフォルダ（`samples`）を Vault として許可**してから開いてください。

## ④ リモート画像（HTTPS・従来どおり）

![リモート画像](https://picsum.photos/640/200)

期待: ネット接続時、従来どおり外部画像が表示される（Vault 許可とは無関係）。

## 確認の観点まとめ

- ① ② が表示される → **ローカル画像表示（FR-18 の主目的）OK**
- Vault フォルダを **未許可** で開くと ① ② がプレースホルダになるはず（許可で表示に変わる）
- ③ がテキストプレースホルダ → 欠落時フォールバック OK
- ④ が表示される → リモート画像は従来どおり OK
- アプリ**再起動後**も ① ② が表示される → bookmark によるスコープ再有効化 OK
